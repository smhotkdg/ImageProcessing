# 신호등 인식 1차시 실습 패키지 — 색으로 찾기 (HSV)

6~11주차 패키지와 같은 구조입니다.
세 시간에 걸쳐 하나의 프로그램을 만듭니다. **오늘은 "찾기"만** 합니다.

| 차시 | 하는 일 | 쓰는 기법 |
|---|---|---|
| **1차시 (오늘)** | 색으로 후보 찾기 | HSV, inRange, bitwise |
| 2차시 | 모양으로 가짜 거르기 | 모폴로지, 윤곽선, 면적·원형도 |
| 3차시 | 동영상에서 상태 판단 | ROI, 다수결 안정화, 저장 |

## 폴더

| 폴더 | 내용 |
|---|---|
| `img/` | 신호등 장면 9장 + `labels.txt` (정답) |
| `starter/` | 학생용 TODO 코드 (여기를 채웁니다) |
| `answers/` | 해설 코드 (수업 후 공개 권장) |
| `expected/` | 예상 결과 이미지 |
| `output/` | 실행 결과가 저장되는 곳 |
| `common.py` | 경로·입출력·색 범위 함수 (수정 불필요) |

### 실습 장면에 대하여

`img/` 의 장면은 **수업용으로 직접 그린 합성 영상**입니다. 실사 사진이 아닙니다.
대신 수업에 필요한 조건과 함정을 의도적으로 모두 넣었습니다.

| 장면 | 노린 것 |
|---|---|
| `tl_day_red/yellow/green.png` | 기본 주간 장면 |
| `tl_night.png` | 야간 — 창문이 노랑 전구와 같은 색 |
| `tl_dusk.png` | 역광·노을 |
| `tl_rain.png` | 비 — 전구가 흐려지고 어두워짐 |
| `tl_blur.png` | 모션 블러 |
| `tl_far.png` | 멀어서 전구가 작게 보임 |
| `tl_none.png` | **신호등이 없는데 빨강이 검출되는 장면** |

모든 장면에 공통으로 들어 있는 가짜 후보:
붉은 `OPEN` 간판 · 차량 제동등 · 가로수(초록) · 가로등(주황) · 야간 창문(노랑).

점등 색과 전구 좌표를 알고 있으므로 채점에 쓸 수 있습니다 (`img/labels.txt`).

**실사 영상으로 바꾸려면**: 직접 찍은 사진을 `img/` 에 넣고
`04_picker.py` 의 트랙바로 그 영상에 맞는 HSV 범위를 다시 재면 됩니다.
`common.py` 의 `RANGES` 를 그 값으로 고치면 나머지 코드는 그대로 돌아갑니다.
(`LAMP_BOXES` 는 합성 장면의 고정 좌표이므로 실사에서는 쓰지 않습니다.)

## 실행

```
pip install -r requirements.txt
python starter/01_channels.py
```

키: `s` 저장 · `q` 종료.
창을 띄울 수 없는 환경에서는 `CV_HEADLESS=1` 을 붙이면 GUI 없이 결과만 저장됩니다.

## 확인해야 할 값

```
전구 중심 (y=66, x=398)
  BGR  낮 (90, 87, 203)   야간 (62, 63, 248)   비 (93, 94, 198)   ← 크게 흔들림
  HSV  낮 (179,146,203)   야간 (0, 191, 248)   비 (0, 135, 198)   ← H 만 고정

전구 세 개의 HSV
  빨강 H179 S146 V203 / 노랑 H25 S140 V209 / 초록 H70 S124 V204

빨강 마스크 (tl_day_red.png)
  H   0-10   1110 화소
  H 170-179  1131 화소
  OR 로 합치면 2241 화소     ← 한쪽만 쓰면 절반을 놓칩니다
  전구 주변 H 값 = {0, 1, 178, 179}

마스크 화소 수 (전체 / 전구 영역 21x21)
  빨강 2241 / 371    노랑 333 / 333    초록 1542 / 373
  → 초록 1542 중 1169 는 전부 가로수입니다

같은 범위, 네 조건에서 전구 영역에 잡힌 화소
  HSV 범위   낮 371  야간 401  역광 373  비 353    ← 안정적
  BGR 범위   낮 239  야간 373  역광 324  비 135    ← 비에서 무너짐

종합 (06_all.py)
  tl_day_red    red 2241  yellow    0  green 1225
  tl_day_green  red 1879  yellow    0  green 1542
  tl_night      red 2317  yellow 5493  green    0
  tl_none       red 1872  yellow    0  green 1186   ← 신호등이 없는데도!
```

## 오늘 알게 되는 한계

- `tl_none.png` 에는 신호등이 없는데 빨강이 1872 화소 나옵니다 (OPEN 간판 1490 + 제동등 4개)
- `tl_night.png` 의 노랑 5493 화소는 전부 건물 창문입니다
- 초록 1542 중 전구는 373 뿐, 나머지는 가로수입니다
- **임계값을 아무리 잘 골라도 이 구조는 해결되지 않습니다.** 다음 주에 모양을 봅니다.

## 자주 나는 오류

- `inRange` 에 리스트를 넘김 → `np.array` 로 감싸야 합니다
- H 를 0~255 로 생각함 → OpenCV 의 H 는 **0~179** 입니다 (각도 ÷ 2)
- 인터넷에서 베낀 범위가 안 됨 → 웹 색상 선택기는 0~360 입니다. 2로 나누세요
- `bitwise_and` 의 `mask` 에 3채널을 넘김 → 1채널 uint8 이어야 합니다
- 빨강이 절반만 잡힘 → 범위를 하나만 썼습니다
